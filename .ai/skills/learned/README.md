# 🧠 Learned Patterns — Kho bài học tự tích luỹ

Thư mục này chứa các "bài học" mà AI ghi lại khi gặp **lỗi/khó khăn lặp đi lặp lại**, để lần sau không vấp lại. Skill [`learn-pattern`](../learn-pattern.md) ghi vào đây.

## Khi nào tạo file mới ở đây
- Một bug mất > 2 lần thử mới sửa được.
- Một "cái bẫy" của Expo SDK 54 / React Native / SQLite mà dễ tái phạm.
- Một quyết định kỹ thuật đã cân nhắc kỹ và không muốn bàn lại từ đầu.

## Mẫu 1 file (1 bài học = 1 file `kebab-case.md`)

```markdown
# <Tên bài học ngắn gọn>

**Bối cảnh:** gặp khi làm gì, ở file nào.
**Triệu chứng:** lỗi/hành vi sai quan sát được.
**Nguyên nhân gốc:** vì sao xảy ra.
**Cách sửa đúng:** bước làm đúng, kèm đoạn code mẫu nếu cần.
**Dấu hiệu nhận biết lần sau:** để phát hiện sớm.
```

> Liên quan: cơ chế memory của Claude Code và skill `systematic-debugging` (native) cũng phục vụ mục tiêu tương tự — dùng file ở đây cho bài học **riêng của dự án** này.
