## Chi tiết kỹ thuật

### settingsStore.ts
```ts
mealWindows: MealWindows;                               // persisted
setMealWindow: (meal, window) => void;                  // updates one meal slot
```
Dùng `zustand/persist` + AsyncStorage như các field khác — không cần thêm kho lưu.

### foodNutrition.ts
Signature mới (backward-compatible):
```ts
mealTypeForHour(hour: number, windows = DEFAULT_MEAL_WINDOWS): MealType
mealTypeForTimestamp(timestamp: number, windows = DEFAULT_MEAL_WINDOWS): MealType
```
`FoodLogModal` không truyền `windows` → tự dùng default → không vỡ.

### energyStore.ts (1 dòng)
```diff
- const mealType = mealTypeForTimestamp(timestamp);
+ const mealType = mealTypeForTimestamp(timestamp, useSettingsStore.getState().mealWindows);
```
`getState()` (không phải hook) vì `logFood` là async action, không phải React component.

### SettingsScreen.tsx — UX changes
- **`SectionHeader`** component: icon emoji + chữ in hoa, thay thế text label đơn độc cũ.
- **`divider`**: dòng ngang `#1e1e30` phân cách giữa các section — rõ hơn `gap` thuần.
- **Gộp NGƯỠNG PIN THẤP → THÔNG BÁO**: logic liên quan (ngưỡng → mới cảnh báo được), giảm số section từ 4 → 3 chính.
- **KHUNG GIỜ BỮA ĂN**: card `#1a1a2e` với 3 dòng bữa, mỗi dòng có chấm màu + `HourStepper` cho start/end. Cảnh báo màu đỏ nhẹ nếu overlap (không chặn cứng — đây là tool tự theo dõi).
